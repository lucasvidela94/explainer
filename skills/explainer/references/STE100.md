# STE100 (text)

Write controlled technical English in ASD-STE100 style (or ~80% if the user asks): one instruction per sentence, max ~20 words, active voice, one term per concept, no jargon.

Structure: what it is, what it does, what changed, how to verify it. Each section cites its source in `out/facts.md`. Nothing beyond the facts.

Open `out/explainer.md` non-blocking (`(nohup xdg-open out/explainer.md >/dev/null 2>&1 &)` Linux, `(open out/explainer.md >/dev/null 2>&1 &)` macOS, `(start "" out/explainer.md)` Windows) so it renders in a markdown reader, and present the content inline in the chat.
